# Agentic Research Patterns — Agent Guide

## What This Project Is

A pattern library, skill set, and tutorial repo for structured multi-pass research with AI agents.

## Current State

Foundational docs, templates, patterns, and skill scaffolds exist. The next layer is refinement: improve pattern definitions, deepen skills, and add better examples and tutorials.

## Working Conventions

- Prefer edits that strengthen structure, clarity, and reusability.
- Keep naming boring, specific, and capability-based.
- When adding a new pattern, define: use when, don't use when, inputs, pass sequence, outputs, quality checks, and failure modes.
- When adding a new skill, keep it narrow and triggerable.
- Preserve the distinction between guides, patterns, skills, templates, and examples.

## What's Next

- Refine pattern docs into stronger, more reusable formats.
- Improve skill scaffolds and add supporting references/templates.
- Build realistic end-to-end examples.
- Decide whether evals and failure modes belong in this repo or a companion repo.
