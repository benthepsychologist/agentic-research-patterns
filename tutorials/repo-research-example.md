# Tutorial: Repo Research from Codebase Map to Plan

This walkthrough demonstrates using a repository itself as the research base.

## Sequence

1. Initiate around a concrete technical question
2. Map the codebase and relevant subsystems
3. Deep-dive on the components that matter
4. Identify dependencies, risks, and likely failure points
5. Synthesize into an implementation or migration plan

## What to Notice

- File citations matter
- Surface mapping is not enough; follow the actual flows
- Separate factual findings from design recommendations
