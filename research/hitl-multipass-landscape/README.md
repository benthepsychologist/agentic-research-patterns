# HITL Multi-Pass Research Process Landscape (Working Folder)

This folder is the active working area for a deep-dive landscape study on human-in-the-loop (HITL), multi-pass, agent-supported research processes.

## Purpose

Organize and execute a long-range landscape pass before formalizing a new pattern/skill in this repository.

## Scope

- Primary: General-purpose HITL multi-pass research standards.
- Secondary: Scientific/evidence-synthesis methods and constraints.
- Output style: Broad-source landscape with explicit evidence-tier differences.

## Deliverables

1. `landscape-plan.md` — pass-based execution plan for this investigation.
2. `citation-schema.md` — simple CSL-JSON profile + tier rubric.
3. `evidence-registry.csl.json` — machine-readable citation list.
4. `evidence-registry.yaml` — mirrored human-readable registry.
5. `scripts/sync_evidence_registry.py` — conversion/validation helper.

## Source Policy (Broad + Transparent)

All sources are included with explicit reliability labeling:

- **T1** Standards / official methodological guidance
- **T2** Peer-reviewed literature
- **T3** Preprints / arXiv
- **T4** Official engineering docs
- **T5** Practitioner posts / repos

The point is inclusion with visibility, not false equivalence.

## Folder Conventions

- Keep raw source collection and final registry in this folder.
- Keep process notes in Markdown.
- Keep IDs stable once assigned.
- Never drop low-tier sources silently; mark tier and limitations explicitly.
