# Research Initiation

## What This Skill Does

Turns a vague topic into a scoped research effort with clear questions, boundaries, pass sequence, and success criteria.

## Use When

- The user says "help me research X" but X is still fuzzy
- The user has a concept but not a plan
- The next move should be Pass 0, not actual evidence gathering

## Deliverable

Produce an initiation document covering:

1. Problem or question
2. What the user already knows
3. What needs to be found out
4. Scope and out-of-scope boundaries
5. Planned pass sequence
6. Success criteria
7. Likely biases and risks
