# Repo Research

## What This Skill Does

Treats the repo as the source material and produces structured findings about architecture, implementation, risk, and next steps.

## Use When

- Mapping an unfamiliar codebase
- Investigating where a feature or subsystem lives
- Producing implementation plans grounded in actual files
- Performing technical due diligence or migration analysis

## Deliverables

- Codebase map
- Architecture findings memo
- Risk register
- Implementation or migration plan
