# Principles

The doctrine behind Agentic Research Patterns.

## 1. Plan Before Pass

Research starts with scope, questions, and sequencing. If you don't know what this pass is for, the agent won't either.

## 2. One Pass, One Job

Each pass should do one coherent thing: map a landscape, go deep on a cluster, audit evidence, synthesize, red-team, or decide. Mixed-purpose passes produce mush.

## 3. Write to Artifacts

Chat is working memory. Files are institutional memory. If the output is worth keeping, it belongs in a file.

## 4. Sources or It Didn't Happen

Strong claims need sources. Weakly sourced claims need confidence labels. Unsourced synthesis is decoration, not research.

## 5. Synthesis Is Separate from Search

Evidence gathering and interpretation are different jobs. Treat them as different passes. This reduces premature convergence and hidden bias.

## 6. Preserve Uncertainty

Good research names what is unknown, contested, weakly sourced, or still a judgment call. The goal is not false certainty; it is calibrated clarity.

## 7. Red-Team Before Commitment

Important conclusions should be stress-tested. Counterarguments, failure modes, and assumption audits are part of the work, not extras.

## 8. Keep State External

Repos, ledgers, summaries, and decision docs beat chat history. Agents are better when context is explicit and durable.

## 9. Progressive Depth Beats Prompt Dumping

Go wide, then narrow, then analyze, then synthesize, then decide. The sequence matters because later passes should stand on earlier passes.

## 10. Tooling Is Replaceable; Patterns Are the Asset

Claude, ChatGPT, Gemini, Codex, and future tools will change. The pattern library is the durable layer.
